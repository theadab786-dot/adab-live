# 🎵 Adab Live — Frontend (Next.js Application)

This directory contains the Next.js 16 App Router application for **Adab Live**.

For the complete project documentation, environment setup, backend integration guide, and feature overview, please refer to the [Root README.md](../README.md).

## Quick Start (Frontend)

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
